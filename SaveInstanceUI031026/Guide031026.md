# Save Instance UI

A UI shell for configuring UniversalSynSaveInstance-style options.

## What it includes

- Draggable dark UI
- Sanitized relative file names
- Binary `.rbxl` or XML `.rbxlx` output selection
- Optimized, full, and scripts modes
- Avoid-overwrite option
- Decompile option
- Nil instances option
- Remove player characters option
- Isolate StarterPlayer option
- Status display
- Save callback interface

## Why the UI uses relative paths

Executor file APIs commonly restrict writes to their own workspace. Absolute Windows paths such as `C:\Users\Name\Desktop\file.rbxl` can therefore produce an `Illegal path` error.

The UI only generates a relative output name such as:

```text
GameName-123456789.rbxl
```

Your save implementation decides where that relative path is written.

## Integration

`SaveInstanceUI031026.luau` returns a function. Call it with an `onSave` callback that accepts the options table.

```lua
local createSaveUI = yourUiLoader()

createSaveUI({
    onSave = function(options, setStatus)
        yourSaveFunction(options)
        setStatus("Finished", "success", "Save function returned.")
    end,
})
```

If you already have a `synsaveinstance` function in your script, use that function as `yourSaveFunction`.

The UI does not fetch, execute, or modify the upstream UniversalSynSaveInstance source itself.
